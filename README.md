# OpenGL RollerCoaster

C++와 OpenGL로 제작한 인터랙티브 3D 롤러코스터 트랙 에디터입니다.
기둥을 직접 배치하고 높이를 조절하면 기둥 꼭대기를 지나는 폐곡선 트랙이 생성되며,
카트의 외부 시점과 1인칭 시점에서 완성된 트랙을 주행할 수 있습니다.

## 핵심 기능

- 탑뷰에서 마우스로 기둥을 배치하는 트랙 편집 시스템
- 정면·측면 직교 화면에서 기둥 선택 및 높이 조절
- 기둥 꼭대기를 제어점으로 사용하는 Catmull–Rom 폐곡선
- 곡선의 접선과 직교 축으로 타원형 레일 단면을 생성하는 3D 메시 구성
- 편집 데이터가 변경될 때만 스플라인과 VBO를 갱신하는 Dirty Flag 최적화
- 스플라인 경로 좌표를 따라 이동하는 카트 위치·진행 방향·자세 계산
- 이전 Up 벡터를 연속적으로 전달하고 수평선을 보정한 안정적인 1인칭 카메라
- 깊이 버퍼와 법선 변환을 적용한 기본 조명 및 가림 처리

## 기술 스택

`C++20` · `OpenGL 3.3` · `GLSL 330` · `GLEW` · `freeglut` · `GLM`

## 실행 방법

별도의 빌드나 OpenGL 라이브러리 설치 없이 다음 실행 파일을 더블 클릭하면 됩니다.

`Release/롤러코스터.exe`

`Release` 폴더의 `vertex2.glsl`, `fragment2.glsl`은 실행에 필요하므로 실행 파일과
같은 폴더에 유지해야 합니다. Windows의 기본 `OPENGL32.dll`과 OpenGL 3.3 이상을
지원하는 그래픽 드라이버는 필요합니다.

### 소스에서 빌드

`롤러코스터.sln`을 Visual Studio 2026으로 엽니다.

1. 상단 구성을 `Debug` 또는 `Release`로 선택합니다.
2. 플랫폼을 `x64`로 선택합니다.
3. 솔루션 탐색기에서 `롤러코스터`를 시작 프로젝트로 설정합니다.
4. `F5`를 누르면 빌드 후 실행됩니다. 디버깅 없이 실행하려면 `Ctrl+F5`를 누릅니다.

솔루션에는 애플리케이션과 `GLEW`, `freeglut` 정적 라이브러리 프로젝트가 들어 있습니다.
GLM은 헤더 전용 라이브러리로 직접 참조됩니다. 세 라이브러리는 모두 `third_party`에
포함되어 있으므로 인터넷 연결, vcpkg 또는 별도의 라이브러리 설치가 필요하지 않습니다.

Visual Studio 2026의 `v145` 도구 집합을 사용합니다. 다른 컴퓨터에서는 Visual Studio
Installer에서 **C++를 사용한 데스크톱 개발**을 설치해야 합니다.

빌드 결과는 다음 경로에 생성됩니다.

- Release: `bin/x64/Release/롤러코스터.exe`
- Debug: `bin/x64/Debug/롤러코스터.exe`

셰이더 파일은 빌드할 때 실행 파일 옆으로 자동 복사됩니다.

#### CMake 빌드

Visual Studio용 CMake가 설치되어 있다면 다음 명령으로도 빌드할 수 있습니다.

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
```

## 조작

- `Z`: 위에서 보는 트랙 편집 화면
- 편집 화면에서 마우스 왼쪽 클릭: 기둥 추가
- `A`: 정면 높이 편집 화면
- `S`: 측면 높이 편집 화면
- 높이 편집 화면에서 기둥 클릭 후 `Q` / `W`: 높이 증가 / 감소
- 빈 공간 클릭: 선택한 기둥 해제
- `M`: 카트 이동 시작 / 정지
- `N`: 카트 1인칭 시점
- `X`: 기본 원근 시점
- `C`: 모든 기둥과 트랙 초기화
- `Esc`: 종료

처음 실행하면 빈 배경이 표시됩니다. `Z`를 누르고 서로 다른 위치를 세 번 이상 클릭하면
기둥 꼭대기를 부드럽게 연결하는 폐곡선 트랙이 생성됩니다.

## 외부 라이브러리

`third_party`에 포함된 GLEW, freeglut, GLM의 라이선스는 각 라이브러리 폴더에 보존되어 있습니다.
